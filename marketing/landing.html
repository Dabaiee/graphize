The pipeline

Seven agents run behind one button.

Each stage returns typed, schema-validated JSON — that's what makes the automation reliable instead of a demo that works once. Structured data builds deterministically; text is mined by parallel extraction.

01
intent
Objective + candidate entity/relationship types, from your form + a data sample.
02
file suggestion
Which files serve the goal, and the role each one plays.
03
schema
The graph schema + concrete build mapping for tables and text.
04
construction
CSV → deterministic nodes/edges. Text → parallel per-chunk extraction.
shipped05
resolution
Merge duplicate entities — “IBM” / “I.B.M.” / “Intl. Business Machines”.
shipped06
critic
Check the graph against the goal; propose questions it can answer.
07
graphrag
Answer questions with full-text retrieval + guarded read-only Cypher.

One graph, two worlds

Structured and unstructured, connected.

CSV · JSON · tables

Deterministic build

Rows become nodes and relationships from a mapping the schema agent proposes. No LLM writes to the database — exact, cheap, repeatable.

Text · PDF · reviews · notes

Parallel extraction

Free text is chunked and mined for entities concurrently, then linked back to the same nodes — so both halves fuse into a single graph.

Run it yourself

One command. Claude is the only key you need.

Neo4j + API + UI come up together. Retrieval is Neo4j full-text — no embedding service to configure.

cd graphize && cp .env.example .env
# set ANTHROPIC_API_KEY in .env, then:
./deploy.sh
